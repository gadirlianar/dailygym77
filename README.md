# APEX BIO 3D (dailygym77)

Çoxfunksiyalı Ev Məşq Stansiyası və Sərbəst Çəkilər üçün 3D Biomexaniki Analiz Sistemi & 4-Günlük Fərdi Proqram.

## 🚀 Xüsusiyyətlər
- **Canlı 3D İdmançı Anatomiyası:** Əzələlərin konsentrik və eksentrik fazalarda real vaxt bio-gərginlik işıqlanması (emissive glow).
- **2-Bone FABRIK İnvers Kinematika (IK):** Tutacaqlara və lat çubuğuna dəqiq oturan əllər və anatomik tutuş bucaqları (`setAnatomicalGrip`).
- **Dinamik Stansiya Simulyasiyası:** Kabel dartılması, relslərdə qalxan çəki plitələri və kəpənək (Pec Deck Fly) qolları.
- **3D Zədə Göstəriciləri:** Tipik icra səhvlərində riskli oynaqlarda (rotator manjet, L4-L5 diskləri, ACL) pulsasiya edən təhlükə halqaları və xəbərdarlıqlar.
- **4-Günlük Balanslaşdırılmış Proqram:**
  - **GÜN 1: İtələmə (Push)** — Chest Press, Pec Deck Fly, Overhead Press, Triceps Pushdown
  - **GÜN 2: Çəkmə (Pull)** — Lat Pulldown, Seated Cable Row, Biceps Curl, Hammer Curl
  - **GÜN 3: Ayaq & Baza (Legs)** — Goblet Squat, Leg Extension, Romanian Deadlift (RDL), Walking Lunge
  - **GÜN 4: Üst Bədən İxtisaslaşması (Upper Volume)** — Chest Press, Lateral Raise, Lat Pulldown, Hammer Curl
- **Məşq Alətləri:** Təkrar sayğacı (Rep Counter), istirahət taymeri və Web Audio API metronomu.
- **Mobil və Planşet Uyğunluğu:** Responsive HUD, sürüşdürülə bilən panellər və toxunma dostu idarəetmə.
